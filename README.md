# Free Technology Courses

A curated directory of official learning platforms and resource collections for engineers, students, and anyone building technology skills.

> **Note:** “Free” generally means the learning content is available without tuition. Certificates, exams, hardware, premium labs, and some advanced courses may still cost money. Check the provider's current terms and eligibility before enrolling.

## Suggested starting points

For embedded engineering, begin with Microchip University, STM32 MOOCs, TI Precision Labs, Arm Education, Intel Developer Training, and NVIDIA DLI. For cloud and general AI foundations, try AWS Skill Builder, IBM SkillsBuild, Microsoft Learn, and Google Cloud Skills.
